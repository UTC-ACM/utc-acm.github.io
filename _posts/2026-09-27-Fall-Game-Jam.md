## 🎮 What is a Game Jam?

A game jam is a short, time-limited event where developers, artists, designers, writers, and other creators come together to create a video game.

Participants usually work around a shared theme. The goal is not to create a perfect or fully polished commercial game. Instead, game jams encourage creativity, experimentation, rapid prototyping, and learning by doing.

For beginners, game jams are a great way to get started with game development. You don't need to be an expert!

You can work:

* **Solo**
* **With a team**
* On programming
* On art
* On music and sound
* On writing
* On game design

You can also use existing tools, tutorials, libraries, and assets where allowed. The goal is to **learn something, finish something, and have fun!**

Some well-known games that originated as game jam projects include:

* Baba Is You
* Celeste
* Superhot
* Hollow Knight
* Surgeon Simulator

## 🛠️ Making Your Game

You can use any game development tools you are comfortable with.

### **Godot**

Godot is a free and open-source game engine used to create 2D and 3D games.

It includes tools for:

* Graphics
* Physics
* Animation
* Audio
* Input
* Scene design
* Scripting

Godot is especially beginner-friendly because its visual editor makes it possible to build games without needing to write everything from scratch.

Godot uses **GDScript**, a scripting language that is easy to learn and has syntax similar to Python.

**Jose Coronado will provide a beginner-friendly introduction to Godot during the October 2 kickoff.**

More tutorials and resources will be shared during the Game Jam.

### **Other Tools**

You are welcome to use other game development tools and engines if you are comfortable with them.

* Godot
* Other frameworks or libraries

If you are new to game development, don't worry about choosing the "perfect" tool. Pick something manageable and start building!

## 💡 Game Design Tips

### Keep Your Scope Small

A tiny finished game is better than a huge unfinished game.

**Good examples:**

* Click to stack blocks
* Dodge falling objects
* Rhythm tapping game
* Simple puzzle game
* One-screen platformer
* Short arcade game

**Probably too ambitious for a Game Jam:**

* Open-world RPG ❌
* Online multiplayer game ❌
* Massive story-driven adventure ❌
* Complex MMO ❌

If your idea sounds like a full commercial game, consider making a much smaller version of it.

### Game = Goal + Obstacle + Feedback

A simple game can often be built around three basic components:

* **Goal:** What is the player trying to accomplish?
* **Obstacle:** What makes the goal challenging?
* **Feedback:** How does the player know what is happening?

**Example:**

* 🎯 Goal: Survive for as long as possible
* 🪨 Obstacle: Falling rocks
* 🔊 Feedback: Sound, animation, and score

That's enough to start building a game!

### Start Small

Don't spend the entire Game Jam planning.

Build a basic playable version first.

Then improve it.

A useful approach is:

**Idea → Prototype → Playtest → Improve → Polish**

## 🤖 Using AI

AI tools may be used in a **limited capacity** during the Game Jam.

You can use AI to help with:

* Brainstorming game ideas
* Learning programming concepts
* Generating or explaining code
* Debugging
* Writing documentation

**AI-generated media assets should not be used in submitted games.** This includes AI-generated images, sprites, artwork, music, sound effects, or other media assets.

However, you should understand and take responsibility for the code and content you submit.

**Please disclose any significant use of AI in your submission.**
